# Audio packs

- `core_sfx/weapons/` — стрельба, перезарядка, пустой магазин.
- `core_sfx/actors/zombies/` — попадания.
- `core_sfx/ui/` — наведение и подтверждение в меню.
- `ambience_pack/` — индустриальный ночной эмбиент.
- `voice_pack/` — стоны и радио-голоса врагов.

Сейчас в каталогах лежат локальные процедурные WAV-заготовки. Их можно заменить своими WAV/OGG, сохранив имена либо обновив preload-пути в скриптах.
