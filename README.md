# Dead Radio — нативная PC-игра

Проект на Godot 4.7.2. Он запускается как обычное Windows-приложение и использует нативный рендерер Godot, а не браузер.

## Запуск и сборка

1. Установите Godot 4.7.2 Standard и откройте `project.godot`.
2. Нажмите F6/F5 в редакторе для запуска.
3. Локальный экспорт: **Project → Export → Windows Desktop**.

Для GitHub Actions создайте репозиторий так, чтобы `project.godot` и папка `.github` из этого проекта находились в корне репозитория, затем отправьте изменения в `main` или `master`. Windows-сборка запускается на push/pull request. Для ручной сборки откройте вкладку **Actions → Build Windows game → Run workflow**. Скачайте и распакуйте артефакт: запускайте `DeadRadio.exe`, оставив рядом файл `DeadRadio.pck`.

## Управление

- WASD — движение; Shift — бег.
- Мышь — обзор; ЛКМ — стрельба; R — перезарядка.
- Esc — пауза.

## Архитектура

- `scenes/` — уровни, персонажи, оружие и UI.
- `scripts/autoload/` — сохранённые настройки и глобальное состояние забега.
- `scripts/characters/` — контроллер игрока, AI зомби и спутницы.
- `scripts/levels/` — сборка арены и менеджер волн.
- `scripts/ui/` — главное меню, настройки и HUD.
- `assets/audio/packs/` — звуковые наборы: оружие, зомби, интерфейс и атмосфера.
- `assets/textures/packs/` — материалы окружения, персонажей и UI.
- `assets/models/`, `assets/materials/`, `assets/shaders/`, `resources/` — модельные исходники и переиспользуемые ресурсы.

Арена, текстуры и звуковые эффекты содержат процедурные стартовые ресурсы, которые можно заменять импортированными файлами. Добавленные персонажи — стилизованные 3D-модели, собранные из геометрии в проекте.

Исходный генератор стартовых WAV и PNG лежит в `tools/`; готовые ресурсы уже включены в проект. Для повторной генерации используется Node.js: `node tools/generate_starter_assets.mjs`.

Подробная схема систем и связей — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
